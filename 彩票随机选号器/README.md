# 彩票模拟选号器

手机端优先的 PWA 静态工具，支持双色球、大乐透、3D、排列3、排列5模拟选号。

## 功能

- 随机选号和自选号码
- 注数 1-50，倍投 1-999
- 双色球、大乐透复式
- 大乐透追加投注
- 3D、排列3定位复式，单位置最多 3 个号码
- 自动计算计费注数和金额
- 一键复制选号结果
- PWA 配置，支持部署后添加到手机主屏幕

## 本地运行

```bash
npm run dev
```

默认地址：

```text
http://localhost:4173
```

手机访问时，需要把项目部署到 HTTPS 静态站点，或让手机访问同一局域网内的本机地址。iPhone 使用 Safari 添加到主屏幕，安卓使用 Chrome 添加到主屏幕。

## 说明

本工具仅作模拟选号和金额计算，不包含历史开奖数据分析，不提供任何中奖预测。
